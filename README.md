# Kolonialgeschichte_Digital_SoSe2026_AI_Network
This project was developed for the course "Kolonialgeschichte Digital" at LMU (Munich) during the summer term 2026. It is a historical network analysis supported by AI in the context of german colonial institutions, companies etc. in Africa around 1900. The data extraction from the historcial sources was done with ´Claude Sonnet 5'.

## Repository Structure:
    - claude_protocols: This folder contains various prompts which were given to Claude over the project,
                        and the corresponding answers.

    - CYPHER_catalogue: This folder contains the CYPHER commands and queries which were used to create the graph
                        database and to query information.

    - json: This folder contains the file 'koloniale_institute_claude_result.json' which was generated by Claude and
            the file 'koloniale_institute_final.json' which is the final version with some corrections.

    - pdf: This folder contains the snippet of the 'Deutsches Kolonial-Handbuch, Band II, 1901' which contained all the
           data for the project.

    - python: This folder contains a python script to analyze the structure of the JSON-file. It may be extended in the future.
    
    - visualization: This folder contains some visualization-versions of the final graph database.


As the project was finalized with the free version of neo4j 'Aura' the graph database is not publicly available.
If you want to get access to the project, you can get in contact with the authors of the project. Otherwise you could
also use the commands from CYPHER_catalogue/coloniale_institute_cypher.cypher to recreate the graph in your own
neo4j-instance.
